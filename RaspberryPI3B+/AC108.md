

есть клон вот такой звуковой карточки с 4-мя микрофонами

[ReSpeaker-4-Mic-Array-for-Raspberry-Pi](https://github.com/SeeedDocument/ReSpeaker-4-Mic-Array-for-Raspberry-Pi)

для проверки, установил на Raspberry PI 3B+, собственно для чего карта и разрабатывалась

оригинальные драйвера, по ссылке, оказались старыми,

нашел решенние

ставим 32 битный дистр BookWorm LTE с kernel 6.12.96

и исправленные дрова из этого репозитария

[seeed-voicecard](https://github.com/PiFlavoredPie/BookWorm-Update-HinTak-seeed-voicecard-x)

~~~
$ arecord -l
**** List of CAPTURE Hardware Devices ****
card 2: seeed4micvoicec [seeed-4mic-voicecard], device 0: bcm2835-i2s-ac10x-codec0 ac10x-codec0-0 [bcm2835-i2s-ac10x-codec0 ac10x-codec0-0]
  Subdevices: 1/1
  Subdevice #0: subdevice #0
~~~


Чтобы убедиться, что микрофоны работают, выполните команду для тестовой записи:

~~~
$ arecord -D plughw:2,0 -f S16_LE -r 16000 -c 1 -d 5 test_1ch.wav

$ arecord -D plughw:2,0 -f S16_LE -r 16000 -c 4 -d 5 test_4ch.wav

~~~

-D plughw:2,0 — указывает использовать вашу карту (card 2, device 0).

-f S16_LE — формат 16-bit.

-r 16000 — частота 16 кГц.

-d 5 — запись длительностью 5 секунд.

-c 4 - где 4 - количество каналов записи, для данной карты, параметр от 1 до 4
