я собирал kernel для OpenWrt 25.12.5
а можно как то добавить в сборку свою директорию с Makefile
со своим отдельным проектом....

один из способов:

## Цель: собрать проект для hlk-7688a на x86-64 компьютере с Linux (можно ещё собрать на Orange pi 5)

## 1.) Сначала делаем как написано в:

[Сборка openwrt](../openwrt/Сборка_openwrt.md)


## 2.) после этого можем добавить свой "проект" в дерево сборки ....

копируем каталог myprg в размещение где собирали openwrt

...  openwrt/package/utils/

в myprg уже все настроено как должно быть, для примера...


## 3.) запускаем make menuconfig

находим в меню utils

пункт myprg, и отмечаем его звездочкой [*]

## 4.) Сборка

make V=s -j8 package/utils/myprg/compile
